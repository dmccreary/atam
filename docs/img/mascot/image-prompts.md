# AI Image Generation Prompts: Vista the Giraffe

These are self-contained prompts for generating each of Vista's seven poses.
**Every prompt embeds the full base character description** so it can be used
independently — just copy one block into your AI image tool (ChatGPT/DALL·E,
Midjourney, etc.).

Recommended: generate at 1024×1024, then trim transparent padding (see the
command at the bottom) and let the CSS scale each image down to ~90px.

> **Consistency note:** Keep the neck **compact / chibi-short**. A realistic
> long giraffe neck disappears at icon size. Keep the body golden-amber with
> reddish-brown patches, round indigo glasses, and a small indigo bow tie in
> every pose.

---

## 1. Neutral / Default Pose — `neutral.png`

```
I am about to ask you to generate seven difference poses for the book mascot Vista the Giraffe.
Please make the style of each pose similar.

Please generate a new pose for Vista the Giraffe.
A modern flat vector illustration of Vista the Giraffe, a friendly pedagogical
mascot for a software architecture textbook. Vista has a golden-amber coat
(#e0a458) with reddish-brown polygonal giraffe patches (#a8682f), small round
indigo eyeglasses (#3f51b5), and a small indigo bow tie. Vista has a big warm
smile, bright curious eyes, and short ossicones (horns) on top. IMPORTANT:
draw Vista with compact, chibi-style proportions and a DELIBERATELY SHORTENED
neck so the whole character reads clearly at small icon sizes. Style: modern
flat vector, clean lines, flat fills, gentle shading. No text in image.

Vista stands upright in a relaxed, neutral pose facing the viewer directly,
with a calm, friendly closed-mouth smile. Hooves rest naturally with no
specific gesture. The pose is balanced and unassuming — a general-purpose
default illustration. Filename: neutral.png

Please generate a new png image now with a fully transparent background now.
The background MUST be fully transparent. DO NOT use a white, black or a
checkered background.
```

## After Generating: Trim Transparent Padding

AI generators add excess transparent padding, which makes Vista appear too
small inside the 90px admonition boxes. Run the trimmer on each file from the
project root:

```bash
python ../claude-skills/src/image-utils/trim-padding-from-image.py docs/img/mascot/neutral.png
python ../claude-skills/src/image-utils/trim-padding-from-image.py docs/img/mascot/welcome.png
python ../claude-skills/src/image-utils/trim-padding-from-image.py docs/img/mascot/thinking.png
python ../claude-skills/src/image-utils/trim-padding-from-image.py docs/img/mascot/tip.png
```
