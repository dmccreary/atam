# Cover Image Prompt

This file documents the prompt used to generate `cover.png` for the
**Architecture Tradeoff Analysis Method** intelligent textbook.
The cover is 1200×630 pixels (1.91:1 Open Graph standard).

Re-generate with:

```bash
python scripts/generate-cover.py
```

That script calls the OpenAI image API with the background prompt below,
then composites `docs/img/mascot/welcome.png` onto the left 20%.

---

## Layout

```
┌──────────┬──────────────────────────────────────────┐
│          │                                          │
│  Vista   │   Architecture diagram montage           │
│ (welcome │                                          │
│  pose)   │   Architecture Tradeoff                  │
│          │   Analysis Method                        │
│  left    │   ATAM                                   │
│  ~20%    │                                          │
│          │   right ~80%                             │
└──────────┴──────────────────────────────────────────┘
```

- **Left 20% (≈240 px wide):** Vista the Giraffe in the welcome/waving pose,
  composited from `docs/img/mascot/welcome.png` (686×803 px after padding trim).
  A soft vertical glow separator divides this zone from the right panel.

- **Right 80% (≈960 px wide):** Architecture montage background generated by
  the OpenAI image API, with the book title centered in the upper-right area.

## Background Image Prompt (sent to OpenAI gpt-image-1)

```
Generate a wide-landscape textbook cover for 'Architecture Tradeoff Analysis Method (ATAM)' —
1536x1024 pixels, no crop needed.

Place the welcome image of the Giraffe mascot Vista in the LEFT 20%.

OVERALL: Dark deep-indigo (#2C3E7A) to navy blue gradient background with very subtle
blueprint grid lines at low opacity.

LEFT 20% Mascot (approximately 0px – 300px of total width): Clean indigo background area,
slightly lighter than the right side.

RIGHT 80% (approximately 307px – 1536px): Rich collage of software architecture
visual elements rendered in blueprint / schematic style:
  • System component boxes with labeled arrows (boxes unlabeled)
  • Quality-attribute radar/spider chart
  • Risk sensitivity matrix grid
  • Utility tree branching diagram
  • Distributed system topology — interconnected server and cloud nodes
  • Container/microservice icons
  • Abstract data-flow arrows in orange and teal accent colors

TITLE TEXT (centered in the right 80% zone, middle-height of the image):
  Line 1 — "Architecture Tradeoff" — large crisp bold white sans-serif, very readable
  Line 2 — "Analysis Method" — same style, same size
  Below the title — "ATAM" — in orange (#FF6D00), slightly smaller

COLOR PALETTE: Deep indigo/navy backgrounds, orange (#FF6D00) and teal (#20B2AA)
accents, white title text. Golden-amber and warm tones only in the leftmost 20% gradient
to suggest warmth where the mascot will sit.

STYLE: Modern professional technical textbook. Clean, not cluttered, blueprint-inspired.

STRICTLY NO: watermarks, logos, trademarks, giraffe or any animals, photographs.
```

## Mascot Composite (applied in Python after API call)

Vista's `welcome.png` is pasted into the left 20% zone after the background is
generated and cropped to 1200×630.

**Composite parameters (see `scripts/generate-cover.py`):**

| Parameter | Value |
|-----------|-------|
| Zone width | 20% of cover width = 240 px |
| Zone height | 630 px (full cover height) |
| Padding inside zone | 12 px on all sides |
| Scaling | Fit within 216×606 px, preserving aspect ratio |
| Alignment | Centered horizontally and vertically in the zone |
| Blend mode | Alpha composite (mascot PNG transparency respected) |
